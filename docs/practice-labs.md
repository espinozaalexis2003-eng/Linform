# Linform practice labs

The production index.html contains both lab implementations and needs no additional deploy assets. The Linux worker is bundled from scripts/terminal-worker.mjs and scripts/linux-builtins.mjs with wasi-sh 0.11.0; the external BusyBox WASM is pinned and integrity checked. Preserve the embedded ISC notice. The Terraform engine is readable in scripts/terraform-simulator.js and embedded as linform-terraform-engine in index.html. Changes to readable sources must also update their embedded versions before deployment. CI tests the embedded production versions.

Linux uses a WASM shell and in-memory filesystem. Helpers add basic manuals, metadata and file tools. ls -l displays virtual permission/ownership metadata; access control is not enforced. Hard links are supported during a worker session but restore snapshots copy their data independently. System, process, user, package and firewall examples are labelled simulations. Remote connections, passwords, ZIP compression and real system administration are unavailable. No AWS CLI, Azure CLI or real cloud resources are connected.

Terraform is a constrained teaching simulator, not the Terraform binary. It supports a small HCL subset (primitive variables, terraform_data input and root outputs), plans, confirmation, saved plans, state operations, workspaces and a limited expression console. Its JSON and formatting output are teaching formats, not complete Terraform interfaces. Advanced Stacks, queries, modules, authentication and .tftest.hcl execution are explained, not implemented. No tokens or credentials are requested. Practice state is temporary and is not saved to student accounts; existing lesson completion sync remains separate.

Run node tests/validate-site.mjs and node --test tests/account-progress.mjs tests/terminal.mjs tests/terraform.mjs from the repository root. Terminal tests download the integrity-pinned WASM; LINFORM_WASM_PATH can point to a matching local fixture. Also run python -m unittest discover -s infra -p 'test_*.py' -v. The Actions deployment runs all checks before uploading index.html and invalidating CloudFront.
