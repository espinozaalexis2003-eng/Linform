# Linform

Learning cloud platform founded by Alexis Espinosa. Learn AWS, Azure, Terraform, and Linux through practical starter lessons.

## Features

- Starter tutorials for Linux, AWS, Azure, and Terraform
- Searchable Linux command reference
- FinanceCorp personal AWS lab case study and architecture diagram
- Lesson completion saved in the learner's browser
- Inquiry form connected to FormSubmit
- Responsive dark theme with blue and purple accents

## Open your website

Download or clone this repository, then open `index.html` in your browser. No build step is required.

For a local web server, if Python is installed:

```bash
python -m http.server 8000
```

Open http://localhost:8000. Stop the server with Ctrl+C.

## Edit

Open `index.html` in VS Code or another text editor. This file contains the HTML, CSS, JavaScript, lesson content, and SVG diagrams.

## Hosting and dependencies

Uploading the code does not deploy it to AWS or enable GitHub Pages. This static site can be hosted under your own account; review current pricing before creating resources.

Google Fonts and external documentation links need internet access. The inquiry form uses FormSubmit; test email delivery after changing domains and complete any new verification prompts.

Progress is saved per browser and domain. No student accounts, payment system, database, or executable online terminal are included.

FinanceCorp is a personal learning project. The diagram represents a simplified original AWS architecture; its Terraform rebuild is marked in progress.

Independent education. Not affiliated with AWS, Microsoft, or HashiCorp.
